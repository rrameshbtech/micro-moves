# AI Design System Instructions: Micro Breaks (Pausify)

## 1. Design Philosophy & Persona

- **Core Principle**: "Less, but better." Every element must serve a functional purpose. If it doesn't aid the user in taking a break, remove it.
- **Inspiration**: Braun-era Dieter Rams (functional minimalism), Early Apple (clarity and hierarchy), and Naoto Fukasawa (intuitive, "without thought" interaction).
- **Interaction Model**: One-handed operation. All primary actions must be reachable within the bottom 60% of the screen.

## 2. Visual Language & Atmosphere

- **Atmosphere**: Peaceful, tranquil, and supportive. The app should feel like a deep breath, not a digital chore.
- **Color Palette**:
  - **Primary**: Soft Sage Green (`#E8F5E9`) or Muted Sky Blue (`#E3F2FD`).
  - **Background**: Off-white or very light gray (`#F9F9F9`) to reduce eye strain.
  - **Typography**: High-contrast charcoal (`#2D2D2D`) for legibility. No pure blacks.
- **Typography**: Use a clean, highly legible Sans-serif (e.g., Inter, SF Pro, or Roboto). Large font sizes for elderly accessibility (Minimum 18pt for body text).

## 3. UI Components (The "Rams" Aesthetic)

- **Buttons**: Large, tactile touch targets (minimum 60px height). Use subtle shadows or soft borders instead of aggressive gradients.
- **Cards**: Use generous white space and soft rounded corners (12px–16px). Avoid "boxy" layouts; use whitespace to separate sections rather than heavy lines.
- **Icons**: Simple, thin-stroke linear icons. Intuitive metaphors only.

## 4. Accessibility Constraints (Elderly-Friendly)

Contrast: Ensure all text passes WCAG AA standards.

Navigation: No hidden menus or complex gestures. Stick to "Tap" and "Scroll."

Cognitive Load: One primary action per screen. Minimize the number of choices presented at any single moment.
